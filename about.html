ABOUT HAHN HEROES

Learning that feels like an adventure.

HAHN Heroes is a free, anime-style learning app made for the 5th and 6th graders at Hahn Intermediate School. Kids pick a hero, practice reading and math, play games with friends, build a base and a room, and earn rewards for effort and for kindness.

09

Safe by design

Free, with no ads

There is no advertising and no purchases. The app uses no analytics or tracking tools.

Very little data

The app stores a generated hero code, a preset hero name, grade, game progress and coins. It does not ask for real names, emails, birthdays, photos, addresses, locations or voice from children.

Sign-in without personal details

A hero code plus a picture password of four pictures, with a QR hero card. A separate friend code is shared with friends, so it never doubles as a login. Repeated wrong guesses trigger longer and longer rests.

No open chat

Names and squad names are chosen from presets, and emotes and stickers are presets too. The only typing between kids is short room chat in a game: 80 characters, links, emails and phone numbers blocked, a language filter and a speed limit. Chat is limited to kids who have joined a teacher’s class, repeated problems pause chat, and a parent can ask the Sensei to unlock it.

Friends need a code

Friends see only name, grade and hero.

Kids see only their own information

Every table in the database is locked down; a parent or teacher can see only their own child or students.

Fair rewards

Coins and purchases are handled by the server and cannot be edited from the app. Mission coins have a weekly limit.

Reported drawings

Reported drawings are hidden right away.

Built with COPPA and FERPA in mind

Families can request deletion by emailing info@detcorddigital.com.

AI is teacher-controlled

Quiz drafts are always reviewed by a teacher before any child sees them, and children do not chat with an AI.
